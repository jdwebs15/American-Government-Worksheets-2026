GOVERNMENT HUB INSTALLATION

Folder name: government-basic-principles-worksheet
Main page: index.html

1. Upload this entire folder inside the Government hub's worksheets folder.
2. Open app.js and replace PASTE_YOUR_APPS_SCRIPT_WEB_APP_URL_HERE with the same deployed Apps Script /exec URL used by the other Government worksheets.
3. Add this link to the worksheet hub:
   worksheets/government-basic-principles-worksheet/index.html

Suggested hub card title:
Basic Principles: Building Depth of Understanding

Assignment ID sent to Apps Script:
gov-basic-principles-2026

The worksheet sends these top-level fields:
action, assignmentId, assignmentTitle, name, period, email, answers, telemetry, submittedAt

Telemetry includes:
startedAt, eventAt, activeSeconds, awaySeconds, tabLeaves, pasteCount, questionSeconds

The page also keeps an automatic browser-local backup as the student types. Retrieval first checks Apps Script and then falls back to that local backup.
